# 👁️ Fright Finder 🔪

**Personalized horror movie recommendation engine that helps users discover their next scary movie based on mood, subgenre preferences, and scare intensity.**

Fright Finder features intelligent filtering and real-time movie ratings to deliver tailored horror recommendations — whether you're in the mood for slow-burn psychological dread or relentless, anxiety-inducing terror.

---

## 🎬 Features

- **Smart Subgenre Filtering** — Browse curated categories including Slashers, Psychological Horror, Supernatural, Possession, Monster Movies, Home Invasion, Slow Burn, and more
- **Natural Language Search** — Search naturally: *"80s slasher movies"*, *"movies like The Shining"*, or *"Stephen King films"*
- **Fuzzy Search & Misspelling Correction** — Handles typos like *"haloween"*, *"heriditary"*, and *"insideous"* gracefully
- **Real-Time Movie Database** — Powered by [TMDB API](https://www.themoviedb.org/) for live data, posters, ratings, and overviews
- **Highly Rated Badges** — Highlights films with a 7.5+ rating and 200+ votes
- **Personal Watchlist** — Save movies with the ⭐ button; watchlist persists across sessions via localStorage
- **Load More Movies** — Incrementally load additional results without losing your place
- **Responsive Dark UI** — Horror-themed interface optimized for desktop and mobile

## 🛠️ Tech Stack

- **Frontend:** Vanilla HTML, CSS, JavaScript (single-file app)
- **API:** [TMDB (The Movie Database) API](https://www.themoviedb.org/documentation/api)
- **Search Intelligence:** Levenshtein distance fuzzy matching, franchise/director keyword mapping, decade-based filtering
- **Storage:** localStorage for watchlist persistence
